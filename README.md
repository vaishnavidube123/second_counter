# Counter BLoC App

A simple Flutter Counter application built using the *BLoC (Business Logic Component)* pattern.

## 🚀 Features

- Increment counter
- Decrement counter
- Reset counter
- BLoC state management
- Clean and simple Flutter UI

## 🛠️ Technologies Used

- Flutter
- Dart
- flutter_bloc
- BLoC Pattern
